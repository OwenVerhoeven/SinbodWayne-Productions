# Design Fidelity Ledger

The approved visual references are preserved under `docs/design/approved/`. They are product-direction artifacts, not runtime fixtures and not Filmcraft assets.

| Surface              | Approved intent                                                                                                     | Verified implementation                                                                                                                  | Deliberate difference                                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Command centre       | Graphite shell, grouped rail, editorial headings, dense readiness/schedule/change panels, restrained amber and cyan | The live overview uses the same hierarchy, proportions, token roles, readiness ring and operational panel language                       | The deterministic project is 100% Ready to Shoot, so illustrative concept blockers are replaced by real green evidence and an empty priority state |
| Screenplay workspace | Structured page canvas, scene outline, revision/sync review, keyboard-oriented controls                             | The screenplay route provides structured blocks, scene navigation, immutable revisions and mapping review inside the shared shell        | Controls follow the implemented accessible component primitives rather than reproducing a concept-only composition pixel for pixel                 |
| Mobile               | Compact project context, touch actions, readable cards and no horizontal trap                                       | The 390 × 844 browser journey uses a collapsed rail, compact header and single-column operational cards with 390/390 print-preview width | The approved image is a three-device montage; the runtime shows one focused workflow per viewport and avoids ornamental device framing             |

Validation on 2026-08-08 compared the approved dashboard and mobile references with Playwright captures at 1586 × 992 and 390 × 844. The implementation preserves the visual family while improving text contrast to WCAG AA and keeping state entirely data-driven. Decorative grain, cinematic transitions, imitation trade dress and fake operational counts were intentionally omitted.
