# Capability Traceability Matrix

This matrix maps the complete required release to concrete implementation targets. `Implemented locally` means the schema/domain, API/policy, UI/state handling and applicable automated/export evidence exist in the verified local release. `External blocker` is reserved for the production Cloudflare action that cannot run without an authenticated account and real resource identifiers; it is not deferred local work.

Concrete implementation anchors: D1 migrations are under `apps/web/migrations/0000-0008`; schema contracts are in `apps/web/src/server/db/schema.ts`; shared calculations and invariants are in `packages/domain`; general persisted modules use `server/records/catalog.ts`, `routes/records.ts` and `records/ModuleRegistryPage.tsx`; specialist writing, operations, planning, readiness, file, share and archive routes/pages live in their named directories; the outbound verifier is `apps/nas-agent`; evidence is under domain/web/NAS tests and `apps/web/e2e/critical.spec.ts`.

Abbreviations: `D` domain/unit test, `I` Worker/D1 integration test, `E` Playwright/end-to-end, `P` print-layout test, `S` security/authorization test.
